# Changelog

All notable changes to this project are documented in this file.

The format loosely follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-08-04

Initial public release: a complete, interactive web prototype of
Guardian AI's frozen Android MVP, implementing every screen and flow
specified in `docs/12`–`15`.

### Added

- **Onboarding flow**: Splash, Permission Explainer, simulated Phone
  State and Accessibility Service permission grants, Set/Edit Emergency
  Contact, and Onboarding Complete, with resume-aware routing that picks
  up mid-flow after a reload instead of restarting.
- **Home dashboard**: live protection status derived from simulated
  permission state, a condensed recent-activity strip, and a one-tap
  repair path into whichever permission is actually missing.
- **Interactive Demo Mode**: a guided, scripted call simulation ending
  in a full-screen, pixel-accurate implementation of the Scam Warning
  screen (instant appearance, no accidental dismiss, automatic
  screen-reader announcement, haptic feedback where supported, and the
  asymmetric three-action stack specified in the frozen UX spec).
- **Alert History**: persisted, reverse-chronological, expandable
  entries generated by completed Demo Mode runs.
- **Settings**: live permission status with repair links, emergency
  contact edit/remove with a confirmation dialog, and a plain-language
  privacy disclosure.
- **A traced design-system component library** (`src/components/
design-system/`): typography, buttons, cards, status pills, dialogs,
  toasts, skeleton loading states, and layout primitives, each citing
  the exact frozen visual-spec section it implements.
- **App-shell-level route transitions**: consistent screen-to-screen
  motion, keyboard focus management on navigation, and screen-reader
  route announcements, with a documented exception for the Scam Warning
  screen's zero-transition entrance.
- **Responsive "phone canvas" framing** for tablet and desktop
  viewports, on top of an already-complete mobile layout.
- Client-side persistence (`localStorage`) standing in for the real
  Android app's Repository layer, no backend, no database, no
  environment variables required to run.

### Fixed

- Duplicate `<h1>` elements on the Demo Mode entry screen and the
  emergency-contact edit screen (accessibility).
- A flash of stale "Protection is off" / empty-history content on Home,
  Settings, and Alert History before persisted state finished loading.

### Removed

- An entire unused, superseded shadcn/ui primitive layer, an unused
  motion-constants module, unused mock data and type exports, and
  orphaned default template assets, none of it reachable from the
  running application (full detail in `docs/reports/
release-candidate-1.md`).

### Known Issues

- One color pairing in the frozen visual specification
  (`protectionOff`/`protectionOffContainer`) computes to 3.03:1 contrast,
  below WCAG AA's 4.5:1 threshold for small text specifically, flagged
  for product sign-off rather than silently changed, since it's a
  frozen-spec value, not an implementation choice. See `docs/reports/
release-candidate-1.md` §3.
- No automated end-to-end/visual test coverage yet; verification to date
  has been build/lint checks plus manual code-level tracing. See the
  manual QA checklist in `docs/reports/release-candidate-1.md` §8.
